Cartas “Abra quando” (open when): ideias e como escrever

Atualizado em 3 de novembro de 20267 min de leitura

Cartas “Abra quando”, as open when letters, são bilhetes escritos com antecedência para alguém abrir num momento específico: quando sentir saudade, quando não conseguir dormir, quando o dia tiver sido ruim. Aqui você encontra uma lista de ideias de cartas “Abra quando”, um jeito simples de escrever cada uma e como montar um conjunto no papel ou no celular.

Elas fazem sucesso entre casais à distância porque deixam você estar presente num momento que provavelmente vai perder. Também são um presente lindo para uma amiga que vai morar longe, um filho que vai começar a faculdade ou qualquer pessoa que vai passar um tempo longe de você.

Como funcionam as cartas “Abra quando”

Cada carta vai no seu próprio envelope, e o envelope diz quando abrir: “Abra quando não conseguir dormir”. O seu amor guarda o conjunto num lugar seguro e abre uma quando aquele momento chegar. Algumas nunca são abertas, e tudo bem. Saber que estão ali já faz parte do conforto.

Um conjunto de oito a doze é mais que suficiente para começar. Poucas cartas escritas com carinho valem mais que uma pilha de trinta feitas às pressas. Dá sempre para mandar mais depois.

Ideias de cartas “Abra quando”

Escolha as que combinam com a vida do seu amor e mude as palavras para que soem como você.

Para os dias difíceis

  • Abra quando o seu dia tiver sido ruim
  • Abra quando não conseguir dormir
  • Abra quando estiver doente
  • Abra quando o trabalho ou as provas estiverem te estressando
  • Abra quando sentir que ninguém te entende
  • Abra quando duvidar de você
  • Abra quando a gente tiver brigado
  • Abra quando bater saudade de casa

Para a saudade

  • Abra quando sentir saudade de mim
  • Abra quando precisar de um abraço
  • Abra quando quiser ouvir a minha voz (com um áudio ou um link para um)
  • Abra quando não lembrar por que a gente faz isso
  • Abra quando a gente tiver acabado de se despedir no aeroporto
  • Abra quando fizer tempo demais que a gente não se vê

Para boas notícias e conquistas

  • Abra quando receber uma boa notícia
  • Abra quando conseguir o emprego
  • Abra no seu aniversário
  • Abra no nosso aniversário de namoro
  • Abra quando a gente tiver marcado o próximo reencontro
  • Abra no seu primeiro dia num lugar novo
  • Abra quando terminar algo pelo qual você batalhou muito

Para momentos do dia a dia

  • Abra quando estiver chovendo
  • Abra num domingo de manhã
  • Abra quando estiver cozinhando só para você
  • Abra numa viagem longa de ônibus ou de avião
  • Abra quando precisar de algo para ler
  • Abra no primeiro dia de frio do ano

Só por diversão

  • Abra quando precisar dar risada
  • Abra quando bater o tédio
  • Abra quando quiser saber um segredo meu
  • Abra quando precisar de uma música (com uma playlist dentro)
  • Abra quando quiser uma ideia de encontro
  • Abra quando já tiver aberto todas as outras

Como escrever uma carta “Abra quando”

Você não precisa saber escrever bonito. Uma boa carta “Abra quando” costuma ter quatro partes, e nenhuma precisa ser longa.

  1. Encontre o seu amor naquele momento. Comece de onde a pessoa está. “Se você está lendo isto, o seu dia foi péssimo, e eu queria muito estar aí.”
  2. Diga algo que só você diria. Uma lembrança real funciona melhor que qualquer gentileza genérica. A noite em que o ônibus quebrou. A piada que fez vocês rirem na fila.
  3. Dê uma tarefinha. Faça um chá. Coloque esta música. Saia cinco minutos para tomar um ar. Uma tarefa pequena ajuda mais que um conselho.
  4. Termine com carinho e simplicidade. Diga quando vocês vão se falar de novo, ou o que você mal pode esperar para viver juntos.

Uma folha de um lado só é suficiente. Escreva à mão se puder: a sua letra faz parte do presente.

Combine o tom com o envelope

Uma carta para um dia ruim deve consolar, não animar a qualquer custo. “Anima, vai” pode soar como bronca. Diga que está tudo bem se sentir um lixo, e que você está do lado do seu amor. Guarde as piadas para o envelope “precisar dar risada”.

Escreva o que vai continuar verdade

A carta pode ser aberta daqui a meses. Evite coisas que podem mudar, como “a gente se vê em três semanas”, a não ser que o envelope seja para uma data fixa. Escreva sobre quem a pessoa é e o que você sente, que dura mais.

Coisinhas para colocar dentro

Qualquer coisa leve e fina pode ir junto com a carta:

  • Uma foto de vocês dois, ou uma que o seu amor nunca viu
  • Um sachê de chá ou de chocolate quente, para o envelope “não consegue dormir”
  • Um ingresso usado, uma flor prensada, um adesivo
  • Um QR code impresso que abre uma playlist ou um áudio
  • Uma receita que você ama, para o envelope “cozinhando só para você”
  • Um “vale” para uma noite de cinema à escolha, ou uma chamada a qualquer hora

Como montar um conjunto no papel

Use envelopes simples e escreva cada frase bem legível na frente. Uma cor por grupo ajuda: azul para os dias difíceis, amarelo para as boas notícias. Numere atrás se quiser que sejam abertas numa certa ordem.

Guarde o conjunto junto numa caixa, com uma fita ou numa pasta, para não se perder numa gaveta. Se der, entregue no fim de uma visita. Deixa a despedida mais leve.

Se for mandar pelo correio, mande cedo. O correio internacional pode demorar, e alguns países restringem o que pode ser enviado, principalmente comida, plantas e sementes. Confira antes de colocar qualquer coisa comestível.

Cartas “Abra quando” no digital

O papel é lindo, mas não é o único jeito.

  • E-mails programados. O Gmail e o Outlook deixam programar um e-mail para ser enviado depois. Funciona para datas fixas, como um aniversário, mas não para momentos, porque não dá para saber quando vai chegar um dia ruim.
  • Uma pasta compartilhada. Coloque cada carta num documento separado, com a frase como título, e peça para o seu amor abrir só a que precisar.
  • Voz e vídeo. Grave uma mensagem curta para cada frase. Ouvir você pode valer mais do que ler você.
  • Um app feito para isso. Alguns apps para casais guardam as cartas lacradas até a outra pessoa decidir abrir.

As cartas digitais têm uma grande vantagem: não dá para esquecer no avião. As de papel têm outra: dá para segurar nas mãos.

Erros para evitar

  • Muitas de uma vez. Comece com algumas. Um conjunto grande demais pode parecer lição de casa.
  • Só envelopes tristes. Equilibre as cartas de dia difícil com boas notícias e cartas só por diversão.
  • Cartas vagas. “Você é incrível e eu te amo” é fofo, mas o que a pessoa vai reler é uma lembrança real.
  • Uma carta no lugar de ajuda. Se o seu amor estiver passando por um momento muito difícil, uma carta conforta, mas não resolve. Inclua uma que diga “Abra quando precisar de mais que uma carta” e, nela, peça para ligar para você, para alguém de confiança ou para quem possa ajudar.

Perguntas frequentes

O que são cartas “Abra quando”?

São cartas escritas com antecedência, cada uma num envelope que diz quando abrir, como abra quando sentir saudade de mim ou abra quando não conseguir dormir. A pessoa guarda as cartas e abre cada uma quando aquele momento chega. Em inglês, são chamadas de open when letters.

Quantas cartas “Abra quando” devo escrever?

De oito a doze é um bom primeiro conjunto. Cobre os dias difíceis, as boas notícias e a saudade sem virar uma obrigação para escrever. Dá sempre para acrescentar mais depois.

O que escrever numa carta “Abra quando”?

Comece pelo momento que a pessoa está vivendo, conte uma lembrança real ou algo que só você diria, dê uma tarefinha, como fazer um chá ou ouvir uma música, e termine com carinho. Uma folha de um lado só é suficiente.

O que colocar dentro de uma carta “Abra quando”?

Qualquer coisa leve e fina: uma foto, um sachê de chá, um ingresso, uma flor prensada, um QR code impresso para uma playlist ou um áudio, uma receita favorita ou um vale feito à mão para uma noite de cinema ou uma chamada.

Dá para fazer cartas “Abra quando” digitais?

Sim. Você pode programar e-mails para datas fixas, guardar cada carta num documento separado numa pasta compartilhada, gravar mensagens de voz ou de vídeo, ou usar um app para casais que mantém as cartas lacradas até a outra pessoa abrir.

Cartas “Abra quando” são só para namoro à distância?

Não. São um presente cheio de cuidado para qualquer pessoa que vai passar um tempo longe de você, como uma amiga que vai morar fora, um irmão que vai começar a faculdade ou uma mãe ou um pai que trabalha longe.
